# Consecuencias

success: prueba confirmada, NPC duda, ruta abierta, faccion dividida.
partial: prueba util con coste, objeto marcado, peligro +1, testigo exige promesa.
failure: ruta bloqueada, NPC huye, faccion hostil, objeto danado.
d6 1-2: energia baja o testigo se asusta.
d6 3-4: prueba se dana pero conserva valor.
d6 5-6: objeto se rompe, enemigo aprende patron, faccion gana posicion.
danger critical: juicio forzado, incendio, transformacion o secuestro de NPC.
