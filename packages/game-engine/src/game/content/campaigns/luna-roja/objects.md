# Objetos

## ritual_tool
Cuchilla dentada de plata vieja. Creada por cazadores para marcar pactos, robada del archivo. La quiere mayor_aldren y old_hunters. Usos: comparar heridas, acusar falsificacion, abrir ruta secret_deep_truth. Riesgo: se corrompe con magia lunar. Estados: intacto, danado, corrupto, perdido, consagrado. Si se rompe conserva valor como prueba danada.

## blood_debt_letter
Carta rota con sello parcial. Creada por una casa menor. Usos: conectar deuda con alcalde. Si esta danada requiere reconstruir patron. Si se pierde abre false_resolution.

## cracked_bell_clapper
Pieza de campana que vibra ante mentiras dichas bajo techo sagrado. Puede ser reliquia persistente.
