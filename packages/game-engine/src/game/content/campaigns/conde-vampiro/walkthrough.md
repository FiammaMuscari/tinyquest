# Walkthrough
Critical path: abrir porton sin despertar casa; leer retratos; bajar a cripta; decidir cena. Opcionales: salvar sirviente, consagrar copa, romper espejo. Fallo: cena forzada con pistas incompletas.
Finales: good_truth_mercy libera conde; heroic_cost quema sangre con perdida; bittersweet_escape heredera huye; tragic_collapse mansion devora invitados; corrupt_victory familia conserva poder; false_resolution matan al conde equivocado; secret_deep_truth revelan asesinato fundador.
Si se repite accion, el retrato aprende y cambia su mentira.
