# Estilo
Gótico elegante, decadencia familiar, velas, terciopelo, plata, copas sin vino, cartas selladas, retratos que miran tarde. Exitos abren puertas o hacen mentir a un retrato. Parciales dan sangre, llave o testimonio con coste. Fallos cierran alas de la mansion, despiertan sirvientes o corrompen objetos.
Prohibido: "la historia avanza", "la escena responde", "la verdad se esconde", "el grupo sabe que". Cada turno debe tocar un objeto o activar un NPC.
