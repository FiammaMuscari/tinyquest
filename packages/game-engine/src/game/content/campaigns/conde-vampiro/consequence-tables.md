# Consecuencias
success: puerta abre, retrato miente peor, sirviente duda.
partial: sangre marca objeto, contrato exige coste.
failure: puerta se cierra, copa se rompe, cazadores irrumpen.
d6 1-2 cansancio o miedo; d6 3-4 objeto danado; d6 5-6 NPC queda atado.
