# El Bosque que Recuerda

Campania de bosque feerico oscuro, memoria robada y pactos con criaturas antiguas. La ruta principal sigue a un pueblo que olvida a sus muertos cada amanecer.

Tema: bosque maldito, romance imposible, fantasmas, deuda familiar.
Duracion: 15 min. Escenas: 3-4. Combate opcional.
